# 문제 정의

대화 내 크로스 모달 상호 참조 해결은 텍스트 표현과 이미지 영역이 같은 상품을 가리키는지 판단하여 군집으로 묶는 과제이다. 이 저장소는 Qwen3-VL-2B-Instruct에 LoRA를 학습하고, 실제 이미지를 제공한 동일한 평가 대화에서 학습 전후 성능을 비교한다.

- 멘션(mention): “이 브라탑”, “이거” 같은 텍스트 구간 또는 이미지 속 상의 영역.
- 참조 대상(entity): 여러 멘션이 함께 가리키는 하나의 상품.
- 군집(cluster): 같은 대상을 가리키는 멘션 ID들의 집합.

텍스트 멘션과 이미지 영역 좌표는 입력으로 주어진다. 모델의 역할은 주어진 멘션들의 연결이며, 멘션 위치를 새로 검출하는 과정은 포함하지 않는다. 이번 평가의 정답에는 텍스트와 이미지 멘션이 함께 있는 군집만 포함한다.

## 실제 예시

첫 번째 이미지의 검은색 브라탑은 M5, 그 이미지를 가리키는 “이 브라탑”은 M4이다. 다른 색상을 요청한 뒤 보여 준 골드 브라탑은 M3이고 “이 골드 색상의 브라탑”(M13), “이거”(M8)가 그 상품을 가리킨다.

```json
{"clusters": [["M3", "M8", "M13"], ["M4", "M5"]]}
```

입력에는 대화·실제 이미지·멘션 목록만 제공한다. 정답 군집과 원본 entity ID는 평가 입력에 넣지 않는다. 상세 저장 형식은 [데이터 포맷](DATA_FORMAT.md), 전체 대화와 이미지 예시는 [성능 분석서](REPORT.md)를 참고한다.
