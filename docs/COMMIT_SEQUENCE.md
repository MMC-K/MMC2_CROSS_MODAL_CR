# 공개 구성 순서

기존 실험의 코드·데이터·분석서를 처음 프로젝트를 구성하는 순서에 맞춰 56개 커밋으로 정리한다. 각 커밋은 실제 파일이나 기능을 추가하며, 과거의 개발 일자를 재현하거나 변경하지 않는다.
