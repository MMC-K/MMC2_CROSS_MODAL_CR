# 이미지 제공 조건의 학습 전후 성능

기준 실험은 학습 2,500건·검증 500건·평가 250건에서 수행한 독립 LoRA 학습이다. 멘션 ID와 표시 순서를 정답과 독립적으로 무작위화한 입력을 사용했다. 최고 검증 exact-cluster F1로 선택된 checkpoint는 epoch 3이다.

| 모델 | Exact-cluster F1 | B³-F1 | LEA-F1 | Cross-modal link-F1 |
| --- | ---: | ---: | ---: | ---: |
| 학습 전 | 0.0000 | 0.3850 | 0.0594 | 0.2324 |
| LoRA 학습 후 | 0.9187 | 0.9801 | 0.9689 | 0.9838 |

모든 점수는 0~1이다. 학습 후 exact-cluster F1은 0.9187이며, 250건 중 전체 군집 구성이 모두 일치한 대화는 225건이다. 두 수치는 집계 방식이 달라 서로 같은 정확도를 뜻하지 않는다.

| 출력 상태 (샘플 수) | 학습 전 | 학습 후 |
| --- | ---: | ---: |
| 유효한 JSON | 221 | 250 |
| JSON 파싱 실패 | 29 | 0 |
| 잘못된 mention ID 포함 | 180 | 0 |
| 512-token 출력 상한 도달 | 29 | 0 |

학습 전 exact-cluster F1이 0이라는 것은 부분적으로 맞힌 연결도 전혀 없다는 의미가 아니다. 완전 일치 기준·출력 형식 오류의 영향을 함께 고려해야 한다. 학습 후에는 군집 연결과 출력 형식이 모두 개선되었다.

이 수치는 하나의 학습 seed와 고정된 후보 무작위화 seed의 결과이다. GPU·라이브러리·배치 구성에 따라 재학습 수치가 달라질 수 있다. 학습과 평가 대화는 겹치지 않지만 카탈로그 이미지 일부는 재사용된다. 관련 분석과 실제 오류 사례는 성능 분석서에 있다.

근거는 `reference_results/IMAGE_ON_RESULTS.json`, 두 모델의 예측 JSONL, epoch별 검증 지표·selection.json·train_metrics.jsonl이다. reference_results/PACKAGE_VALIDATION.json은 2026-11-13 공유 패키지 검증 기록이며, 이번 GitHub 배포 점검은 docs/RELEASE_VALIDATION.json에 별도로 기록한다.
